1.Storage and Accessibility: Explain why it is important to store and organise your files
eﬃciently. 
Answer:Storing and organising files efficiently makes it easier for all team members to find what they need without wasting time searching through unrelated documents. It also reduces the risk of accidentally using an outdated file or losing important data during a long research project.

2.File Storage Methods: Specify which data types may require special access controls. Explain your reasons.
Answer:We would store literature review documents and drafts on a shared GitHub repository since they are not sensitive. Survey data and analysis scripts would be kept in a private repository so only team members can access them. Interview transcripts and consent forms need the strictest access controls, restricted to the core research team only, because they contain personal participant information that must stay confidential under research ethics requirements.

3.Why is it important to have a good naming convention?
Answer:A good naming convention makes it easy to identify what a file contains without having to open it, which saves a lot of time when working with a large number of files. It also helps the whole team stay consistent, so nobody gets confused about which version is the latest or what a file is for.
